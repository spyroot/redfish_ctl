# Compatibility Package

This package is a thin dependency redirect to
[`redfish_ctl`](https://pypi.org/project/redfish-ctl/) and ships no code.

## Install `redfish_ctl` Directly

```bash
pip install redfish_ctl
```

- **Package:** `redfish_ctl` — a vendor-neutral Redfish/BMC CLI (Dell iDRAC, Supermicro incl.
  GB300/X10, HPE iLO, and generic DMTF Redfish).
- **Source & docs:** https://github.com/spyroot/redfish_ctl
